# Key Tester

Показывает каждое нажатие аппаратной клавиатуры (KeyDown/KeyUp, keycode, scancode, meta, устройство),
считает DOWN/UP по каждой клавише и помечает ⚠:
- потерянный UP,
- дребезг (два DOWN быстрее 60 мс),
- слишком короткое нажатие (< 25 мс).

Колонки: DOWN, UP, ДРБ (дребезг), КОР (короткие), -UP (DOWN без UP).

## Сборка
Залей папку в новый репозиторий GitHub → Actions → Build APK → скачай артефакт `KeyTester-apk`.
